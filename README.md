# Done for Windows

Done is a desktop app for tasks, lists, calendars, habits and countdowns.

**[Download Done 0.1.0 for Windows](https://github.com/Soufiane-Fartit/Done-Releases/releases/download/v0.1.0/Done-Setup-0.1.0-x64.exe)**

[Latest release](https://github.com/Soufiane-Fartit/Done-Releases/releases/latest)

No GitHub account is needed to download, install or update Done. Run the installer;
it adds Done to the Start Menu. Windows 10 (version 2004 or later) and Windows 11
on x64-compatible PCs are supported. If Microsoft WebView2 is missing, setup
downloads it automatically, so an internet connection is needed for that step.

Use Settings → Updates in Done to check for and download future updates. Fully
quit Done from its tray menu before continuing in the update installer. Updates
and uninstall keep your local data and settings.

This is an early preview. The installer is not yet Windows code-signed, so Windows
may show a publisher/reputation warning. Public Google Calendar sign-in is still
being prepared; the current Google project accepts approved test accounts only.
Local task management does not require a Google account. Export a backup from
Settings → Data before important migrations or moving to another computer.

This repository hosts installers and signed update metadata. The app's source
repository is private.
